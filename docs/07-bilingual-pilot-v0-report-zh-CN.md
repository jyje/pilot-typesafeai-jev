# 双语分诊试点：v0 报告

**快照日期：** 2026-10-22
**状态：** 探索性参考标签，尚非独立裁定的黄金集

## 摘要

本报告记录一个小规模英语-韩语标注试点，以及另一个双语可用性筛查的运行检查点。这是进度描述，不是模型质量评估。本地审阅快照包含 60 个项目的完整标注，以及对其中 8 个项目的部分第二人标注。双重标注数量少且不完整，无法据此建立最终黄金集或作出广泛的一致性结论。

## 标注快照

试点包含 60 条双语消息，标注维度为意图、紧急程度、提示注入尝试和建议路由。一位评审者标注了全部 60 项，第二位评审者标注了其中 8 项。没有记录证明这 8 项是随机抽取的，其余 52 项目前只有一个已记录标签。

对 8 个重叠项目的一致性描述：

| 维度 | 标签一致 |
| --- | ---: |
| 意图 | 6 / 8 (75%) |
| 紧急程度 | 6 / 8 (75%) |
| 提示注入尝试 | 8 / 8 (100%) |
| 建议路由 | 6 / 8 (75%) |
| 四个维度完全一致 | 2 / 8 (25%) |

这些只是极小且不完整重叠样本的原始计数。本报告不提供机会校正的一致性统计量或总体估计。

完整 60 项标注的边际计数如下。这些数据描述一位评审者的标签，不应视为已验证的真实分布或标准答案。

## 独立可用性筛查检查点

实验台账是运行元数据，不是准确性证据。记录显示第 291 轮完成了 8 个请求；第 292 轮完成时没有新增待处理的筛查任务。本报告不公开逐项提示、供应商输出、请求标识符或逐模型性能。可用性筛查、此标注试点、确认实验和稳定性阶段彼此独立。

## 解读与局限

- 单人完成全部标注并不能建立黄金标准。
- 60 项中只有 8 项记录了两个标签，且没有证据表明这些重叠项目是随机抽样的。
- 观察到的一致性仅为描述性计数，不能估计全部项目的一致性。
- 数据集规模小且由人工整理，不能证明生产性能、语言均衡、安全性、准确率或校准效果。
- 本报告有意排除原始消息、评审者代码、逐项标注、私有数据库内容和模型响应数据。
- 汇总计数来自本地标注快照。私有原始记录未纳入仓库，因此远程读者无法仅凭本报告独立重新计算这些数字。

## 后续步骤

1. 第二位评审者在看不到现有标签的情况下，独立标注剩余 52 项。
2. 保留每项的两份独立标签，再依据书面标准共同审查分歧。共识标签应与原始判断分开保存。
3. 只有在全部 60 项都完成两人评审，且分歧已解决或明确标记为未解决后，才冻结并版本化双人参考清单。私有原始记录应保留来源信息和内容哈希；公开版本必须经过隐私审查和脱敏。
4. 达到上述条件前，不得将当前标签称为最终黄金标签，也不得据此声称确认准确率或稳定性。

本 v0 是本地汇总标注和台账状态的快照，不包含私有源数据。复现标注汇总需要后续经过隐私审查、并附有模式和验证流程说明的导出文件。本报告不包含任何新增推理或供应商请求。
