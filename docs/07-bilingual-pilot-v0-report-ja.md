# バイリンガルトリアージ試験: v0 レポート

**スナップショット:** 2026-10-22
**状態:** 探索用の暫定ラベル。独立判定済みのゴールドセットではありません。

## 概要

本レポートは、小規模な英語・韓国語アノテーション試験と、別途実施されたバイリンガル可用性スクリーニングの運用チェックポイントを記録します。モデル品質の評価ではなく、進捗を記述するものです。ローカルのレビュー記録には60項目すべてのラベルと、8項目に対する部分的な2人目の評価があります。重複評価が少なく不完全なため、最終ゴールドセットや一般的な評価者間一致を確立することはできません。

## アノテーションのスナップショット

試験には、意図、緊急度、プロンプトインジェクションの試み、推奨ルートをラベル付けした60件のバイリンガルメッセージがあります。1人目の評価者は60件すべてを評価し、2人目は8件を評価しました。この8件が無作為抽出であるという記録はなく、残る52件には1つのラベルしかありません。

重複する8項目での記述的一致:

| 項目 | ラベル一致 |
| --- | ---: |
| 意図 | 6 / 8 (75%) |
| 緊急度 | 6 / 8 (75%) |
| プロンプトインジェクションの試み | 8 / 8 (100%) |
| 推奨ルート | 6 / 8 (75%) |
| 4項目すべてが完全一致 | 2 / 8 (25%) |

これは少数かつ部分的な重複に対する単純集計です。偶然一致を補正した統計量や母集団の推定値は報告しません。

60項目全体の周辺度数を示します。1人の評価者によるラベルの記述であり、検証済みの実際の分布や正解として解釈してはいけません。

| 項目 | ラベル数 |
| --- | --- |
| 意図 | アカウント 17; 請求 18; 技術 13; 雑談 6; その他/不明 6 |
| 緊急度 | 0: 27; 1: 14; 2: 19 |
| プロンプトインジェクションの試み | いいえ 43; はい 17 |

## 別個の可用性スクリーニングのチェックポイント

実験台帳は運用メタデータであり、正確性の証拠ではありません。記録上、サイクル291では8件のリクエストが完了し、サイクル292では新しい保留中のスクリーニング作業を追加せずに完了しました。本レポートでは、項目ごとのプロンプト、プロバイダー応答、リクエスト識別子、モデル別性能を公開しません。可用性スクリーニングと本アノテーション試験は、確認実験および安定性段階とは別です。

## 解釈と限界

- 1人による全件評価だけではゴールド基準を確立できません。
- 60件中、2つのラベルが記録されているのは8件だけで、無作為抽出の根拠もありません。
- 観測された一致は記述的な集計であり、全項目の評価者間一致を推定するものではありません。
- データセットは小規模で手作業によるものです。実運用性能、言語間の同等性、安全性、正確性、キャリブレーションは示しません。
- 元のメッセージ、評価者コード、項目別アノテーション、非公開データベースの内容、モデル応答は意図的に除外しています。
- 集計値はローカルのアノテーション記録から読み取ったものです。非公開の原記録をリポジトリに含めていないため、リモートの読者はこのレポートだけから数値を独立して再計算できません。

## 次の手順

1. 2人目の評価者が既存ラベルを見ずに残り52項目を独立して評価します。
2. 全項目の独立した2つのラベルを保持し、記載済みの基準に従って不一致を共同で確認します。合意ラベルは元の判断と分けて記録します。
3. 全60項目に2人の評価があり、不一致が解決済みまたは未解決と明記された後に限り、2人評価の参照マニフェストをバージョン固定します。非公開の原記録には出所とコンテンツハッシュを残し、公開版はプライバシー確認済みのサニタイズ済み成果物に限ります。
4. この条件を満たすまでは、現在のラベルを最終ゴールドと呼んだり、確認精度や安定性の主張に使ったりしません。

## 再現性

本v0は、ローカルに記録されたアノテーション集計と台帳状態のスナップショットです。非公開の原資料は含みません。集計を再現するには、スキーマと検証手順を明記したプライバシー確認済みの後続エクスポートが必要です。本レポートには追加の推論やプロバイダーリクエストは含まれていません。
